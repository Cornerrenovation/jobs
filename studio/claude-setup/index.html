Set up Claude for sourcing

Four steps, about 20 minutes, no terminal. At the end Claude knows how Corner searches, screens and logs for every role you hire, and you've checked that it works.

  • Claude Pro or higher
  • GitHub account
  • Mac or Windows
0 of 4 done
1

Your accounts

5 minutes · today
  1. Claude. Claude Code comes with the Pro plan and above; the free plan doesn't include it. If your plan is free, write a comment on the "Set up Claude" task in your Onboarding tab before you pay for anything.
  2. GitHub. Sign in at github.com, or create a free account. Write your GitHub username as a comment on the same task.
  3. The invitation. Kostya then invites you to Corner's private hiring repo. Accept it from the GitHub email, or at github.com/Cornerrenovation/hiring.
2

Get the hiring repo on your computer

5 minutes
  1. Install GitHub Desktop and sign in with your GitHub account.
  2. File › Clone repository › Cornerrenovation/hiring › choose a folder you'll find again, for example Documents › Clone.

The repo holds the sourcing skill, the scorecards and playbooks it reads, and your search logs. GitHub Desktop is also how you'll save your work and get updates.

3

Open it in Claude

5 minutes
  1. Install the Claude desktop app from claude.ai/download and sign in with your Claude account.
  2. Click the Code tab. This is Claude Code, the version that works with files.
  3. Click the project folder control next to the environment selector and choose the hiring folder from step 2 (the one with README.md in it). If Claude asks whether you trust this folder, say yes: it's Corner's.
4

Check that it works

5 minutes · three checks

Check 1: the skill is there. Type:

Which skills do you have in this folder?
You should see corner-sourcing in the answer.

Check 2: it knows Corner. Type:

What does the corner-sourcing skill cover? Three lines.
You should see version v0.1, the three roles in order (Kitchen Sales Designer, then Project Manager, then Technical Designer) and "pool first" as the first step of a search.

Check 3: your work reaches Kostya. Type:

Add my first feedback: how this setup went, in one line.
You should see Claude add a line to FEEDBACK.md. Then in GitHub Desktop: the change shows on the left; write "Setup check" as the summary, click Commit to main, then Push origin.

All three passed? Comment Claude ready on the "Set up Claude" task. Your feedback line reaches Kostya with the next sync.

If something's off

What you seeWhat to do
corner-sourcing isn't in Check 1Claude is open in the wrong folder. Choose the hiring folder itself, the one that has README.md, then ask again.
The Code tab asks you to upgradeYour Claude plan is free. Comment on the task; don't pay before Kostya answers.
GitHub Desktop can't find Cornerrenovation/hiringThe invitation isn't accepted yet, or you're signed in with a different GitHub account.
Push origin is refusedClick Fetch origin, then Pull, then Push origin again.
Anything elseComment on the task with a screenshot. It reaches Kostya in Slack.

Every day after this

  • Start of the day: GitHub Desktop › Fetch origin, then Pull. That brings any update to the skill or the documents.
  • Work: open the Code tab in the hiring folder and ask in your own words: "plan today's sales designer search", "check my message to Brenda before I send it", "write today's search log". Claude prepares and checks; you send every message yourself.
  • End of the day: commit and push in GitHub Desktop, so your search log and feedback reach Kostya.
  • When the skill is wrong or missing something, tell Claude. It writes your words into FEEDBACK.md, and Kostya goes through it with you every week.
